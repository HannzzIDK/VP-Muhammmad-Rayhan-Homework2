H1 - Justifikasi tema

Seed color yang di pilih untuk aplikasi ini adalah amber. Pemilihan warna ini di dasarkan pada karakteristik dari target user berupa individu yang cenderung menunda pekerjaan dan butuh sistem positive reinforcement visual untuk membangun suatu kebiasaan.

Dalam konteks gamifikasi, warna Amber secara universal diinterpretasikan oleh user sebagai simbol dari pencapaian, koin dan hadiah dari suatu misi. Dengan menggunakan warna ini sebagai fondasi dari user interface, aplikasi secara psikologis mengubah persepsi pengguna yang dimana mereka tidak lagi melihat layar tersebut sebagai daftar to-do list melainkan sebagai quest board yang penuh dengan peluang untuk mendapatkan hadiah.
